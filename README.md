# Система заявок в службу поддержки (Вариант 10)

Индивидуальный мини-проект по дисциплине «Программирование на PHP».

## 🎯 Цель проекта
Организовать создание и обработку обращений пользователей (клиентов и операторов) с серверной валидацией, хранением данных в JSON и защитой от CSRF-атак.

## 🛠 Технологический стек
* **PHP** 8.4+ (со строгой типизацией `declare(strict_types=1)`)
* **HTML5 / CSS3** (интерфейс)
* **JSON** (хранение данных во внешнем файле)

## 📁 Структура проекта
* `public/index.php` — Главная страница со списком всех обращений.
* `public/create.php` — Форма создания новой заявки.
* `public/operator.php` — Защищенная панель оператора для смены статусов.
* `src/functions.php` — Бизнес-логика, работа с JSON и проверка CSRF-токенов.
* `var/data/tickets.json` — Файл хранения заявок.

2. Откройте терминал в корневой папке проекта.
